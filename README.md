# dusentsofttech

**Dusent Soft Tech** - Technology • Skills • Opportunities.

A modern Django web platform offering software engineering services, programming courses across multiple languages, and 100% placement training programs.

## Features
- 🚀 Responsive Glassmorphism 3D UI
- 💻 Comprehensive Programming Courses with live syllabus & validity
- ⚡ Project Cost & Timeline Estimator API
- 📞 Direct WhatsApp & Form Enrollment Integration
- 📱 100% Mobile & Tablet Optimized
- ⚡ High Performance & Optimized Core Web Vitals
